# Config

The Config page shows the settings MLM is running with, as read from your configuration file. It is for viewing only. To change a setting, edit the file and restart MLM, as described under [Configuration](../configuration.md).

The page is organised in boxes:

- **General settings** – the settings that apply everywhere, such as the intervals between runs and which file types you prefer.
- **qBittorrent** – a box for each torrent client. Passwords are hidden.
- **Autograbbers** – a box for each autograbber, with the search it uses. Its **search on MaM** link opens the same search on MyAnonamouse so you can see what it would find.
- **Goodreads lists** – a box for each list and the rules for what to grab.
- **Tags** – rules for tagging torrents in your torrent client. The **apply to all** button applies a rule to all existing torrents in the client you pick. Use it only if you want to tag older torrents too.
- **Libraries** – where your books are stored, and which torrents go where.

See [Configuration](../configuration.md) for what each setting means.
