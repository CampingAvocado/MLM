# Torrents

This page lists every torrent that MLM knows about. That includes torrents it downloaded for you and torrents you added yourself.

## Finding torrents

- **Search** – type in the box and press Enter to filter the list. Click the cross next to the box to clear it.
- **Columns** – tick the extra columns you want, for example *Authors*, *Narrators*, *Series*, *Language*, *Size*, *Filetypes*, *Path*, *Added At* and *Uploaded At*. The *Flags* column shows small icons for content warnings (such as crude language, violence, explicit content, abridged or LGBT).
- **Page size** – how many torrents are shown per page.
- Click any heading to sort, and click a value in a row to filter by it (see the [overview](./overview.md)).

## The table

Each row shows the torrent type, title and whichever other columns you picked. The **Linked** column says whether the torrent has been placed in your library. If you tick **Path**, it shows the actual folder instead.

Some rows carry a small warning sign:

- **⚠ next to a title** – the torrent has been removed from MyAnonamouse but is still being seeded.
- **ℹ next to a title** – the torrent is not in your torrent client, so it is not seeding.
- **⚠ next to the link status or path** – the book no longer sits where your current settings say it should, or is no longer wanted in the library. Hover over it to see the details.

At the end of each row are the **open**, **MaM** and **ABS** links.

## Actions

Tick one or more torrents and these buttons appear:

- **refresh metadata** – fetches the latest information about the book from MyAnonamouse.
- **refresh metadata and relink** – does the same, then moves the files in your library if the new information changes where they belong.
- **clean torrent** – removes the book from your library folders.
- **remove torrent from MLM** – makes MLM forget the torrent.

## The torrent page

Clicking **open** on a row shows everything about that one torrent: title, authors, series, narrators, size, files, where it is in your library and its status in your torrent client. From there you can, among other things:

- edit its information by hand with **edit**,
- stop or start the torrent, and change its category and tags in your torrent client,
- see the history of what MLM has done with it under **Events**,
- refresh, relink, clean or remove it, as on the list page.
