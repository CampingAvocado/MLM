# Replaced Torrents

When a better version of a book arrives, for example an m4b audiobook that replaces an mp3 one, MLM takes the old version out of your library. Those old versions are listed here.

Each entry consists of two rows. The first is the old torrent, with the time it was replaced and the time it was added. Underneath it, marked **replaced with:**, is the torrent that took its place.

## What you can do

Use **Columns** to choose which details are shown, and **Page size** to set the number of entries per page. Tick one or more entries to use these buttons:

- **refresh metadata** – fetches the latest information from MyAnonamouse.
- **refresh metadata and relink** – the same, and then puts the files in the right place in your library.
- **remove torrent from MLM** – makes MLM forget the torrent.

If there is nothing to show, the page says *You have no replaced torrents*.
