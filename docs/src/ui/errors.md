# Errors

When something goes wrong while MLM is downloading, linking or cleaning a torrent, it is listed here, so problems don't go unnoticed.

## The table

- **Step** – where the problem happened (for example grabbing, linking or cleaning).
- **Title** – the torrent it concerns.
- **Error** – what went wrong, in the program's own words.
- **When** – the time it happened.
- **open** / **MaM** – open the torrent in MLM or on MyAnonamouse, when it is known.

Click **Step** or **Title** values to show only errors of one kind or for one torrent. Click the headings to sort.

## Clearing errors

Tick the errors you have dealt with, then press **remove** to clear them from the list. If you don't see any errors, the page says *There are currently no errors*.
