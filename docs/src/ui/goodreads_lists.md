# Goodreads lists

If you have set up [Goodreads lists](../goodreads.md), this page shows them. MLM uses the lists to look for the books you want on MyAnonamouse.

## The lists page

Each list is shown with its name and when it was **Last updated**. Click the name to open it.

Below the active lists, you may see **Inactive Lists**. These were removed from your configuration but are still remembered. MLM no longer refreshes them or searches for their books.

## A single list

A list shows every book on it, with its cover, title, author and series. You can narrow the list down with **Show**:

- **All** – every book,
- **Any Missing** – books where you are still missing the audiobook or the ebook,
- **Audio Missing** – books you have no audiobook for,
- **Ebook Missing** – books you have no ebook for.

For each book MLM tells you what it did:

- *Downloaded* – MLM selected a torrent for it.
- *Suggest wedge* – a matching torrent was found but is large enough that a wedge is suggested.
- *Skipped* – MLM skipped it because it found another version, such as an ebook.
- *Found matching … in library* – you already have it.
- *Audiobook missing* / *Ebook missing* – nothing suitable has been found yet.

Each book also has a **search on MaM** link, a **goodreads** link and a link to the torrent that was found. If you decide you don't want a missing book after all, press **mark done** and MLM stops looking for it.
