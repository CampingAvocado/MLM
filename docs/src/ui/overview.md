# UI

MLM has a web interface that you open in your browser. Along the top of every page is a row of buttons that take you to the different screens:

**Home**, **Torrents**, **Events**, **Search**, **Goodreads lists**, **Errors**, **Selected Torrents**, **Replaced Torrents**, **Duplicate Torrents** and **Config**.

The following pages describe each screen in that order.

## Things that work the same on most pages

**Tables of torrents.** Several pages show a table with one row per torrent. They share a few habits:

- **Sorting:** click a column heading to sort by it. Click again to reverse the order.
- **Filtering:** click a value in a row, such as an author, a series or a type, to show only the rows with that value. Hold **Shift** while clicking to add the filter on top of the ones you already have.
- **Columns:** where there is a *Columns* row of tick boxes, use it to show or hide extra columns.
- **Page size:** where there is a *Page size* choice, use it to pick how many rows are shown at once. Page links at the bottom let you move between pages.
- **Selecting rows:** tick the box at the start of a row to select it, or tick the box in the heading to select every row. The action buttons at the top of the page only appear once something is selected.
- **Links on each row:** **open** shows MLM's own page for the torrent, **MaM** opens it on MyAnonamouse, and **ABS** (if you have set up Audiobookshelf) opens it there.

**Buttons that ask first.** Buttons that remove something show a confirmation question before they do anything.
