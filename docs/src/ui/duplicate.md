# Duplicate Torrents

When MLM finds a torrent it would normally pick, but you already have that book, it doesn't download it. These skipped torrents are listed here so that you can overrule MLM.

Each entry consists of two rows. The first is the torrent that was skipped. Underneath it, marked **duplicate of:**, is the torrent that you already have. The **Linked** column says whether that one is in your library.

## What you can do

Tick one or more entries to use these buttons:

- **replace original** – use the skipped torrent in place of the one you have.
- **remove duplicate** – dismiss the entry and keep what you have.

The links at the end of each row open the torrents in MLM, on MyAnonamouse or in Audiobookshelf. If there is nothing to show, the page says *There are currently no duplicate torrents*.
