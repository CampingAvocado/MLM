# Search

Search lets you look for torrents on MyAnonamouse and download them straight from MLM, without leaving the page.

Type what you are looking for in the box and press Enter. Use the cross next to the box to clear it.

## The results

Each result shows:

- the category icon and, next to it, icons for the price (freeleech, VIP or personal freeleech) and for content flags,
- the title (click it to open MLM's page for the torrent), the authors, series and narrators, plus the file types, audio details and number of comments,
- the number of files and the size,
- the date it was added and who uploaded it,
- the number of seeders, leechers and completed downloads.

Clicking an author, narrator or series name searches for that name. Clicking an uploader's name shows only that person's uploads.

## Downloading

The arrow button in each row selects the torrent for download. After you click it, it turns into a green tick. A green tick that was already there means MLM already has the torrent, or is downloading it.

If you have set a size limit for wedges in your configuration (see [Search](../search.md)), big torrents get a blue arrow instead. That means the torrent will be downloaded using a wedge.
